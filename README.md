# Calculadora CS 1.6
Pequeño proyecto de calculadora interactiva realizada en HTML, CSS y JavaScript para la asignatura Lenguaje de Marcas inspirado en la bomba y menús de Counter Strike 1.6.
Se recomienda utilizar la calculadora con audio para observar su funcionalidad completa.

---

Para acceder a la calculadora puedes entrar a:
<pre>https://tonigstm96.github.io/CalculadoraCS1.6/</pre>
o clonar el repositorio utilizando el siguiente comando en Git Bash:
<pre>git clone https://github.com/tonigstm96/CalculadoraCS1.6</pre>
